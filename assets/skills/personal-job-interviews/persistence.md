# Persistência — vagas e entrevistas

> Leia antes de criar/atualizar notas do dossiê.

## Sempre atualizar (quando houver fato novo)

1. `Processo.md` — status, timeline, contato.
2. `Índice.md` da raiz (`Vagas e entrevistas/`) — tabela Ativas / Arquivo.
3. `por-data/YYYY-MM/Índice.md` — linha com data do evento.
4. Se origem LinkedIn: bloco curto em `Pessoal/LinkedIn/Oportunidades.md` com **wikilink** para o dossiê (não duplicar o briefing inteiro).
5. Se houver data de entrevista: `Trabalho/Agenda/` (`Índice.md` + `Ativas.md`) e, se o dia for hoje/amanhã, diária opcional.

## Pós-entrevista

Preencher seção “Pós-entrevista” do `Briefing — …md` no mesmo dia ou na manhã seguinte: perguntas feitas, impressão, próximo passo, follow-up.

## Sensível

- Faixa salarial / stock / pretensão: **só no cofre** (`Processo.md`), nunca em chat-log.
- Não copiar conteúdo confidencial de empregador anterior para o dossiê público de narrativa; usar `Portfólio técnico.md` sanitizado.

## Encerrar processo

1. Status no `Processo.md` → aceita | recusada | arquivada (+ motivo 1 linha).
2. Mover linha de Ativas → Arquivo no `Índice.md` raiz.
3. Se **aceitou**: avisar o usuário para bootstrap `Trabalho/_template-empresa/` .
