# Projetos e pipeline

Fontes: S6 (blog oficial, agosto de 2023), S12 (mudar etapa do pipeline), S13 (importar candidatos), S5 (projetos com IA). Ver `SOURCES.md`.

Um **Projeto** é o espaço de trabalho de uma vaga ou de um banco de talentos.

1. **Padrão de nome**: combine com o time, por exemplo `Cargo - Local - AAAA-MM` (consultorias acrescentam o cliente) (S6).
2. **Busca e Spotlights dentro do projeto**: refine o *talent pool* com competências, setor, escola, tipo de vínculo; use Open to work, Active talent e Internal candidates (S6).
3. **Recommended Matches todo dia**: uma ação (salvar, ocultar, mensagem) a cada 24 horas para receber até 25 perfis novos por dia (S6).
4. **Alertas**: "Save search" + "Receive alerts for this search", diário ou semanal (S6).
5. **Etapas do pipeline**: as padrão são *Uncontacted*, *Contacted* e *Replied*; o administrador pode criar etapas extras (ex.: Triagem, Entrevista com gestor, Proposta). Mude a etapa pela aba Pipeline, opção "Change stage" (S6, S12). Use as mesmas etapas em todos os projetos para os relatórios fazerem sentido.
6. **Tags e notas**: marque "silver medalists" (finalistas que não foram contratados) para vagas futuras; registre contexto em notas para o time. Tags são criadas pelo administrador; ao importar candidatos só dá para usar tags que já existem (S6, S13).
7. **Colaboração**: na aba de configurações do projeto, adicione colegas ou gestores com acesso total, só ao pipeline ou só leitura, e transfira a responsabilidade quando preciso (S6).

Boas práticas de uso:
- Nota boa é fato verificável ("disponível a partir de março; pretensão informada na conversa de 10/11"), não opinião sobre a pessoa.
- Não registre dados sensíveis (saúde, família, religião) em notas: elas ficam visíveis para o time.
- Feche o ciclo: candidatos que pararam no pipeline merecem retorno.
