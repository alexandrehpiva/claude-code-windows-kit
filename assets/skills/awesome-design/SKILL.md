# awesome-design

**Princípio:** um `DESIGN.md` é um documento de texto que descreve a linguagem visual de uma marca (cores, tipografia, espaçamento, botões, cartões, regras de uso). Com ele em mãos, o resultado fica consistente em vez de "genérico de IA".

Esta skill inclui uma cópia de ~84 arquivos da coleção [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (licença MIT, em `LICENSE` nesta pasta). Cada arquivo é uma **interpretação inspirada** feita pela comunidade, não um manual oficial da marca.

## Como usar

1. Abra `INDEX.md` para ver as marcas e a descrição de cada uma.
2. Escolha com o usuário a marca de referência (pergunte se ele não indicou). Se o pedido for vago, sugira 2 ou 3 opções com uma frase de motivo cada.
3. Leia o arquivo inteiro em `brands/<marca>.md` antes de desenhar.
4. Gere a peça usando os valores do arquivo (cores em hexadecimal, famílias de fonte, raios, espaçamentos). Não invente valores que o arquivo não traz.
5. Se a fonte proprietária da marca não estiver disponível, use uma fonte parecida e diga isso ao usuário.

## Regras

- **Inspiração, não cópia.** Não use logotipo, nome ou textos da marca de referência na peça final. É para a linguagem visual, não para se passar pela marca.
- **Uso interno de uma empresa:** a peça final deve ter a identidade da empresa do usuário. Se ele tiver uma marca própria (cores, logo), ela vence a referência; use o `DESIGN.md` só para estrutura e ritmo visual.
- **Acessibilidade:** confira o contraste de texto sobre fundo. Se o arquivo da marca trouxer uma combinação de baixo contraste, avise e proponha ajuste.
- **Não cite dados reais de terceiros** (pessoas, candidatos, salários) em peças de exemplo; use exemplos fictícios.
