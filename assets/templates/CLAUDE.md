# CLAUDE.md — {{COFRE}}

Instruções permanentes para o Claude neste Cofre. Edite à vontade: este arquivo é seu.

## Como trabalhar

- Responda sempre em português do Brasil, com linguagem simples e direta.
- Antes de alterar ou apagar arquivos do Cofre, diga o que vai fazer. Não faça mudanças que não foram pedidas.
- Quando faltar informação para decidir, pergunte em vez de inventar. Nunca invente dados de pessoas, empresas, salários ou datas.
- Cite de onde veio cada informação (arquivo do Cofre, link, texto colado pela pessoa).

## Dados de pessoas (RH e recrutamento)

- Currículos, avaliações e dados de candidatos e colaboradores são dados pessoais (LGPD). Use apenas o necessário para a tarefa e não copie esses dados para fora do Cofre.
- Nunca peça nem registre senhas, tokens, CPF, documentos ou dados bancários nas conversas ou em arquivos do Cofre.
- Não use características protegidas (idade, gênero, raça, religião, orientação sexual, deficiência, estado civil, gravidez, nacionalidade) para pontuar, filtrar ou ranquear pessoas.
- O Claude apoia a análise, mas a decisão final sobre contratar, promover ou desligar é sempre de uma pessoa. Deixe isso claro nos resultados.

## Estrutura

- `Vagas e entrevistas/` — uma pasta por empresa/vaga, com descrição, perfil, roteiro e anotações.
- `Notas/` — anotações soltas.
- `.claude/skills/` — as skills (rotinas especializadas) deste Cofre. Para criar uma nova, peça: "crie uma skill para ...".
