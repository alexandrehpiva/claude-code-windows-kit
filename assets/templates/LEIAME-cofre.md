# Seu Cofre

Esta pasta é o espaço de trabalho do Claude. Abra sempre pelo atalho da Área de Trabalho: assim ele enxerga o `CLAUDE.md` e as skills daqui.

## Primeiros passos

1. Abra o atalho. Na primeira vez, o Claude pode pedir login ou mostrar um aviso do modo sem permissões.
2. Teste: "o que você consegue fazer neste Cofre?"
3. Peça uma tarefa: "escreva a descrição da vaga de Analista de RH" ou "avalie este currículo contra esta vaga" (cole o texto).

## Dicas

- `/mcp` mostra se o navegador (Playwright) está conectado.
- Para criar uma rotina nova: "crie uma skill para <o que você faz toda semana>".
- Não cole senhas nem documentos pessoais de candidatos na conversa.
